   download-and-execute one-liner. Latest verified release was **v0.19.12 (2026-06-09)**;

   tag, or a release binary plus checksum. [S]

   fixes, `nsite` logging, and podcast-kind support — none were mentioned; the 6-concept
   map predates them. [S]
   *Closed since:* the skill's command reference is now pinned to v0.22.3.

   GitHub shows 'no license'. [S]
   *Closed since:* the repository now ships a `LICENSE` file.

  smoke test remains open.
