# nak-skill

Agent skill for the [`nak` CLI](https://github.com/fiatjaf/nak) (Nostr Army Knife).

`SKILL.md` is a command routing table checked against nak 0.21.x (`go install github.com/fiatjaf/nak@latest` or `brew install nak`). Secrets stay in `NOSTR_SECRET_KEY`, not on `--sec`. Edge cases are in `references/command-shapes.md`.

## Install

Upload `SKILL.md` as a `.skill` package to your agent's skill library, or clone this repo into your skills directory.
